# Небо

Адаптивний сайт погоди українською. Показує актуальну погоду, прогноз на 24 години й на тиждень. Місто можна знайти вручну або визначити за геолокацією. Перемикач °C / °F і вибране місто зберігаються в браузері.

Картка «Час для прогулянки» оцінює найближчі 36 годин. Вона враховує денне світло, імовірність опадів, вітер і температуру за відчуттями, пропускає години з грозою чи сильним вітром і показує умови біля вибраного часу.

## Запуск

Потрібен Python 3 для локального сервера й Node.js 24 для перевірок. Сайт складається зі статичних файлів у `dist/`.

```sh
python3 -m http.server 8000 --directory dist
```

Відкрий http://localhost:8000. Геолокація потребує дозволу браузера та працює на HTTPS або localhost.

```sh
npm test
```

## GitHub Pages і CI/CD

У публічному репозиторії відкрий **Settings → Pages** та вибери **GitHub Actions** як джерело. Workflow **Погода — CI/CD** з файлу `.github/workflows/pages.yml` перевіряє pull requests і зміни в `main`. Після успішної перевірки `main` він публікує `dist/` на GitHub Pages. Перший запуск також доступний через **Actions → Run workflow**.

Дані прогнозу й пошуку міст надає [Open-Meteo](https://open-meteo.com/). Для цього навчального сайту ключ API не потрібен.
